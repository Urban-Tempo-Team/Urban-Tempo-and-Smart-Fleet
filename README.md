# Project Charter: Urban Tempo Smart Fleet & Transit

## Project Overview
Project Manager: Andrew Hendrickson  
Project Sponsor: Katherine Kopp  
Target Launch Date: November 20, 2026  

### Executive Summary
Urban Tempo will develop an IoT Telemetry & Predictive Maintenance Platform for its 350-vehicle transit fleet. The system will use real-time vehicle data to predict maintenance needs, automate work orders, and provide live route updates.

### Problem Statement
Urban Tempo currently relies on spreadsheets and post-failure maintenance logs. This results in unexpected breakdowns, high emergency repair costs, inefficient route detours, and reduced rider satisfaction.

### Strategic Alignment & Benefits
The project supports Urban Tempo's goal of creating a more reliable and efficient public transit system. Key benefits include reduced maintenance costs, fewer vehicle breakdowns, improved fleet availability, better route coordination, and increased rider satisfaction.
